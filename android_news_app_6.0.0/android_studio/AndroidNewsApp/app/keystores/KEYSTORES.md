## 🛡️ Recommended Security & Backup Rules

1. **Keep GitHub Repository Private:**
   - Your code and keystores are currently committed to repository `amaldo123/android_app`.
   - Ensure the repository visibility is set to **Private** on GitHub: `https://github.com/amaldo123/android_app/settings`.
   - If you ever plan to make the repository Public, you must remove `.jks` files from Git history and use **GitHub Encrypted Secrets** instead.

2. **3-2-1 Backup Strategy:**
   - **Copy 1 (Active):** In project directory (`app/keystores/`).
   - **Copy 2 (Local Safe Vault):** `C:\Users\hp\Android_Keystores_Backup\` and Desktop.
   - **Copy 3 (Off-site Cloud):** Upload `Android_Keystores_Backup_2026.zip` to your personal Google Drive, OneDrive, or a password-protected USB flash drive.

3. **Google Play Console / Firebase Integration:**
   - When configuring **Firebase Authentication**, **Google Sign-In**, or **Google Play App Signing**, use the **SHA-1** and **SHA-256** fingerprints listed above for each specific app.
